# QR Facility Manager v1 Design

## Goal
현장 설비를 자유 등록하고 QR로 즉시 조회·점검하며, 점검/정비/사진 이력을 한 휴대폰에서 완전 오프라인으로 관리하는 Android APK.

## UX
- 다크 네이비 기반의 전문적인 카드형 UI, 큰 터치 영역과 최소 입력.
- 홈: 전체 설비, 정상, 이상, 오늘 점검 현황과 빠른 QR 스캔.
- QR 스캔 후 한 화면에서 설비정보 + 오늘 점검 + 최근 정비이력 표시.
- 상태는 정상/주의/이상/미점검으로 명확히 구분.

## Equipment
- 설비 종류 자유 등록.
- 위치 계층 자유 등록: 동 → 층 → 구역/실 → 설비.
- 기본 정보: 이름, 관리번호, 종류, 위치, 제조사, 모델, 일련번호, 설치일, 사양, 메모.
- 각 설비는 변경되지 않는 UUID를 가지며 QR에는 `facilityqr://equipment/<uuid>`만 저장. 설비정보를 수정해도 QR 재출력 불필요.

## QR
- 설비 등록 시 QR 자동 생성.
- QR + 설비명 + 관리번호 + 위치를 라벨 형태로 표시/인쇄 가능한 PDF 생성.
- 스캔 시 로컬 DB에서 UUID로 설비 조회.

## Inspection
- 설비별 점검항목 자유 구성.
- 입력형: 숫자, 정상/이상, 선택, 메모.
- 숫자형은 최소/최대 정상범위를 선택적으로 지정하며 입력 즉시 정상/이상 자동 판정.
- 점검 결과는 설비별 이력으로 누적.

## Maintenance
- 고장/정비 기록: 작업내용, 작업자, 일시, 전 사진, 후 사진, 메모.
- 설비 상세에서 최근 정비이력 확인.

## Storage
- v1은 회원가입/서버 없는 단일 휴대폰 완전 오프라인.
- 구조화 데이터는 로컬 DB, 사진은 앱 전용 저장소.
- 향후 서버 공유형으로 확장할 수 있도록 설비 UUID와 저장 계층을 분리.

## Backup / Restore
- 전체 DB, 사진, 버전 메타데이터를 하나의 백업 ZIP으로 내보내기.
- 새 휴대폰/재설치 후 같은 파일로 복원.
- 복원 전 파일 버전/구조 검증, 실패 시 기존 데이터 유지.

## Android Architecture
- Kotlin + Jetpack Compose.
- Room DB.
- CameraX + ML Kit Barcode Scanning for QR.
- 앱 전용 파일 저장소 + Storage Access Framework로 백업/복원 파일 선택.
- Android PdfDocument로 QR 라벨 PDF.
- UI/도메인/데이터 저장을 분리해 향후 공유 서버 추가 가능.

## v1 Screens
1. 홈 대시보드
2. QR 스캔
3. 설비 목록/검색/위치 필터
4. 설비 등록/수정
5. 설비 상세 + 오늘 점검
6. 점검항목 편집
7. 점검 이력
8. 정비 등록/이력
9. QR 라벨/PDF
10. 관리: 종류/위치/백업/복원

## Constraints
- Android APK.
- 오프라인에서 핵심 기능 100% 사용 가능.
- 서버/로그인 없음.
- 기존 `program2`, `GeumtoPhotoCleaner` 저장소는 변경하지 않음.
- 사용자 데이터 삭제/복원 등 파괴적 작업은 확인 절차를 둠.
