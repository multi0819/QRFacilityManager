# 회의 전달사항 기록 앱 설계

## 목표

업무 회의의 전달사항을 음성 또는 직접 입력으로 기록하고, API 키나 회원가입 없이 휴대폰 안에서 요약·검색·관리하는 별도 Android APK를 만든다.

## 화면 구성

- 카카오톡처럼 익숙하고 깔끔한 대화형 화면을 사용한다.
- 상단에는 회의 주제, 날짜, 시작·종료 시간을 표시한다.
- 가운데에는 음성 변환문과 직접 입력문을 시간순 말풍선으로 표시한다.
- 하단에는 음성 입력, 글 입력, 요약 버튼을 항상 보이게 둔다.
- 큰 글자와 큰 버튼을 사용하고 불필요한 안내문과 복잡한 메뉴를 없앤다.

## 기록 흐름

1. 새 회의를 누르면 날짜와 시작 시간이 자동 입력된다.
2. 사용자는 음성 입력과 직접 입력을 자유롭게 번갈아 사용한다.
3. 음성은 글로만 변환하며 녹음 원본은 보관하지 않는다.
4. 사용자는 변환된 글을 수정하거나 삭제할 수 있다.
5. 요약 버튼을 누르면 전달사항, 담당 업무, 기한, 주의사항, 확인사항, 추천사항으로 정리한다.
6. 저장 시 종료 시간과 수정 시간이 자동 기록된다.

## 오프라인 요약 및 추천

- 외부 AI, API 키, 로그인 없이 휴대폰에서 동작한다.
- 문장에 포함된 담당자 표현, 날짜·시간, 요청·지시·완료 표현을 분석해 항목별로 분류한다.
- 추천사항은 담당자 누락, 기한 누락, 모호한 지시, 결과 보고 방식 누락, 확인 필요 표현을 찾아 제안한다.
- 자동 분류 결과는 사용자가 직접 수정할 수 있다.
- 분석이 불확실하면 내용을 임의로 확정하지 않고 `확인 필요`로 표시한다.

## 저장과 검색

- 회의 주제, 날짜, 시작·종료 시간, 원문, 요약, 담당자, 기한, 추천사항을 휴대폰 내부 데이터베이스에 저장한다.
- 날짜, 주제, 담당자, 원문, 요약, 추천사항을 통합 검색한다.
- 최근 회의와 날짜별 회의 목록을 제공한다.
- 텍스트만 저장하여 용량을 최소화한다.

## 관리 기능

- 기록 수정, 삭제, 복사, 카카오톡 공유를 지원한다.
- 삭제 전 확인 창을 표시한다.
- 앱 삭제나 휴대폰 교체에 대비해 전체 기록을 파일로 내보내고 복원할 수 있게 한다.

## 기술 구성

- Kotlin, Jetpack Compose, Room 데이터베이스를 사용한다.
- Android 음성 인식 기능으로 음성을 글로 변환한다.
- 음성 인식의 네트워크 필요 여부는 휴대폰에 설치된 음성 인식 서비스에 따르며, 글 입력·저장·검색·요약은 오프라인에서 동작한다.
- 민감한 업무 기록은 외부 서버로 전송하지 않는다.

## 완료 기준

- 음성과 직접 입력을 한 회의에서 함께 사용할 수 있다.
- 요약 결과에 전달사항, 담당 업무, 기한, 확인사항, 추천사항이 나타난다.
- 앱을 종료하거나 휴대폰을 재부팅해도 기록이 남는다.
- 검색어가 원문 또는 정리 항목에 있으면 해당 회의를 찾는다.
- 녹음파일을 남기지 않는다.
- APK가 자동 검사와 빌드를 통과한다.
