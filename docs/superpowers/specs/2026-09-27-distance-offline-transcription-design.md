# 장거리 오프라인 회의 녹음·변환 설계

## 목적

회의 전달사항 앱이 휴대폰에서 2~3m 떨어진 사람의 일반 대화와 TV·스피커 음성을 녹음하고, 사용자가 중단 버튼을 누른 뒤 전체 내용을 빠짐없이 텍스트로 변환하도록 한다. API 키나 외부 서버는 사용하지 않는다.

## 성공 기준

- 사용자가 `녹음 시작`을 누른 시점부터 `녹음 중단`을 누를 때까지 시간 제한 없이 원음을 연속 저장한다.
- 가까운 음성만 받는 기존 `SpeechRecognizer` 연속 호출 방식에 의존하지 않는다.
- 휴대폰 마이크에 실제로 들리는 2~3m 거리의 대화와 TV·스피커 음성을 변환 대상으로 포함한다.
- 녹음 도중 인식 결과가 확정되거나 삭제되지 않으며, 중단 후 전체 녹음을 순서대로 변환한다.
- 전체 원문을 먼저 보존하고, 별도의 후처리 단계에서 철자·문법과 문장부호를 정리한다.
- 정리된 전체 원문을 바탕으로 제목, 전달사항, 담당 업무, 기한, 주의·확인사항, 추천사항을 생성한다.
- 변환과 저장이 완료되면 임시 녹음 파일을 삭제해 저장공간 사용을 줄인다.

## 선택한 방식

`AudioRecord` 기반 원음 녹음과 앱 내장 오프라인 한국어 음성변환 모델을 결합한다. 녹음 중에는 음성인식 엔진이 문장을 임의로 확정하지 않고 PCM 오디오를 연속 저장한다. 사용자가 중단하면 저장된 오디오를 짧은 구간으로 나누어 순서대로 변환하고 하나의 전체 원문으로 합친다.

이 방식은 앱 용량, 배터리 사용량, 변환 대기시간이 증가하지만 API 키 없이 장시간 음성을 보존하고 기존 방식의 중간 누락을 피할 수 있다. 인식률은 휴대폰 마이크 성능, 거리, TV 볼륨, 반향 및 주변 소음에 영향을 받으므로 모든 환경에서 완전한 인식을 보장하지는 않는다.

## 대안과 선택 이유

### Android 기본 음성인식 유지

앱 용량은 작지만 가까운 발화에 맞춘 잡음 제거와 구간 종료 판단 때문에 먼 음성·TV 음성이 누락될 수 있다. 현재 문제의 근본 원인이므로 제외한다.

### 외부 음성변환 서비스 사용

정확도와 속도를 높일 수 있지만 네트워크와 API 키가 필요하고 회의 음성이 외부로 전송된다. 사용자 제약과 맞지 않아 제외한다.

### 외부 마이크 사용

녹음 품질을 개선할 수 있지만 별도 장비가 필요하다. 앱은 유선·블루투스 마이크가 연결되면 사용할 수 있게 하되 필수 조건으로 삼지 않는다.

## 구성 요소

### RecordingController

- 마이크 권한을 확인한다.
- `AudioRecord`를 시작하고 사용자가 중단할 때까지 PCM 데이터를 임시 파일에 기록한다.
- 녹음 경과 시간과 입력 음량을 화면에 전달한다.
- 화면 꺼짐과 앱의 일시적인 백그라운드 전환 중에도 녹음이 끊기지 않도록 포그라운드 서비스를 사용한다.

### TranscriptionEngine

- 내장된 한국어 지원 오프라인 모델을 초기화한다.
- 긴 녹음을 겹치는 구간으로 분할해 문장 경계의 단어 누락을 줄인다.
- 구간별 결과를 시간 순서대로 합치고 겹친 문장을 제거한다.
- 진행률과 실패 상태를 화면에 전달한다.

### TranscriptPostProcessor

- 원문을 삭제하지 않고 별도 필드에 보존한다.
- 반복어, 띄어쓰기, 철자, 문장부호를 규칙 기반으로 정리한다.
- 업무 관련 표현을 특정 단어 하나에 의존하지 않고 문장 의미와 날짜·담당자·행동 표현을 함께 사용해 분류한다.
- 분류 근거가 없는 항목은 `없음` 또는 `미정`으로 표시하고 같은 문장을 여러 항목에 복제하지 않는다.

### MeetingRepository

- 날짜·시간, 제목, 원문, 교정문, 요약을 휴대폰 내부에 저장한다.
- 검색은 제목, 원문, 교정문, 요약 전체를 대상으로 한다.
- 임시 오디오는 변환과 저장 성공 후 삭제한다. 실패 시 재시도를 위해 유지하며 사용자가 직접 삭제할 수 있게 한다.

## 사용자 흐름

1. 사용자가 `녹음 시작`을 누른다.
2. 앱은 원음을 저장하면서 경과 시간과 음량 표시를 갱신한다.
3. 사용자가 `일시정지`하면 파일 위치를 유지한 채 수집을 멈추고, `계속`을 누르면 같은 회의에 이어 기록한다.
4. 사용자가 `녹음 중단`을 누른다.
5. 앱은 전체 오디오를 오프라인으로 변환하며 진행률과 남은 처리 상태를 표시한다.
6. 전체 원문과 교정문을 표시하고 교정문 전체를 기본 선택 상태로 둔다.
7. 사용자가 `요약`을 누르면 업무 중심 구조로 요약하고 날짜·시간과 함께 저장한다.

## 오류 처리

- 저장공간 부족을 녹음 시작 전과 녹음 중 주기적으로 감지하고, 안전하게 중단해 이미 녹음된 부분을 보존한다.
- 전화 수신, 다른 앱의 마이크 점유, 권한 취소가 발생하면 이유를 표시하고 복구 가능한 파일을 유지한다.
- 변환이 중단되면 완료된 구간 위치를 저장해 처음부터 다시 처리하지 않고 재개한다.
- 모델이 없거나 손상되면 녹음 원본을 삭제하지 않고 복구 안내를 표시한다.

## 저장공간과 개인정보

- 16kHz 단일 채널 음성을 사용해 인식에 필요한 품질과 파일 크기의 균형을 맞춘다.
- 장시간 녹음은 압축 가능한 무손실 또는 저손실 임시 형식을 검토하되, 변환 엔진 입력 품질을 떨어뜨리지 않는다.
- 모든 녹음과 텍스트는 앱 내부 저장소에 두며 외부 서버로 전송하지 않는다.
- 변환 완료 후 원본 자동 삭제를 기본값으로 하고, 사용자가 원본 보관을 선택할 수 있게 한다.

## 검증

- 0.5m, 2m, 3m 거리에서 동일한 한국어 시험 문장을 녹음해 누락률을 비교한다.
- TV 뉴스를 2~3m 거리에서 재생해 5분 이상 녹음하고 처음·중간·끝 내용이 모두 변환되는지 확인한다.
- 30분 이상 연속 녹음에서 자동 중단, 문장 덮어쓰기, 중간 내용 삭제가 없는지 확인한다.
- 일시정지와 계속을 반복한 뒤 문장 순서가 유지되는지 확인한다.
- 화면 꺼짐, 앱 백그라운드 전환, 전화 수신, 저장공간 부족 상황을 시험한다.
- 변환 실패 후 재시도와 성공 후 임시파일 삭제를 확인한다.
- 요약 결과가 원문에 없는 담당자나 기한을 만들어내지 않는지 확인한다.

## 제외 범위

- 여러 화자의 이름을 자동으로 식별하는 기능
- 잡음이 매우 큰 장소에서의 완전한 인식 보장
- 전화 통화 상대방 음성의 직접 녹음
- 외부 클라우드 음성변환 서비스
