## 실제 회의 흐름

- [ ] 2~3m 거리의 여러 화자가 5분 동안 자연스럽게 대화한다.
- [ ] 처음·중간·마지막 발언이 모두 남는다.
- [ ] 앞에서 변환된 내용이 뒤 발언 때문에 사라지지 않는다.
- [ ] `일시정지` 후 `계속`해도 문장 순서가 유지된다.
- [ ] 화면을 끄거나 앱을 백그라운드로 보내도 녹음이 유지된다.
- [ ] 30분 연속 녹음이 자동으로 끝나지 않는다.
- [ ] `녹음 중단`을 누른 뒤에만 전체 변환이 시작된다.

## 복구와 저장

- [ ] 마이크를 다른 앱이 점유하면 이미 녹음한 파일이 남는다.
- [ ] 변환 실패 후 `다시 변환`이 처음부터 녹음하지 않고 동작한다.
- [ ] 변환 성공 후 원문과 교정문이 저장되고 임시 녹음파일이 삭제된다.
- [ ] 앱을 다시 열어도 전체 원문과 요약이 남아 있다.
- [ ] 제목·원문·교정문·요약의 단어로 검색된다.

## 요약 품질

- [ ] 원문 전체가 교정 입력창에 자동 선택된다.
- [ ] 담당 업무, 기한, 주의·확인사항, 추천사항이 구분된다.
- [ ] 원문에 없는 담당자·날짜·업무를 만들어내지 않는다.
- [ ] `작업`이라는 단어가 없어도 행동 지시가 업무로 분류된다.

## 출시 판정

2m와 3m 시험에서 주요 전달사항이 유지되고, 5분·30분 시험에서 처음·중간·끝 내용이 남으며, 재시도와 저장이 모두 통과해야 배포용으로 판정한다. 하나라도 실패하면 APK를 시험용으로 유지하고 원인과 실제 변환 결과를 기록한 뒤 조정한다.
